# Batalha da Tabuada 🎮

Um jogo educativo interativo para ensinar multiplicação de forma divertida!

## 📚 Sobre

**Batalha da Tabuada** (BDT) é um jogo desenvolvido para alunos do 2º ao 5º ano, com o objetivo de tornar o aprendizado da tabuada mais engajador, dinâmico e divertido.

### Características:
- ✅ Interface interativa e colorida
- ✅ Sistema de pontuação e ranking
- ✅ Cronômetro para desafios contra o tempo
- ✅ Feedback visual e sonoro
- ✅ Multiplataforma (mobile, tablet, desktop)
- ✅ Funciona offline (Progressive Web App)

## 🚀 Como Jogar

1. Acesse o jogo [aqui](https://victorytips26-ai.github.io/batalha-da-tabuada)
2. Selecione a tabuada (2 ao 5)
3. Responda as questões o mais rápido possível
4. Vença e suba no ranking!

## 💻 Tecnologia

- HTML5
- CSS3
- JavaScript (Vanilla)
- Progressive Web App (PWA)
- Service Worker para offline

## 📱 Instalação no Celular

### Android:
1. Abra o jogo no Chrome
2. Toque nos 3 pontos ⋮
3. Selecione "Instalar aplicativo" ou "Adicionar à tela inicial"

### iOS:
1. Abra no Safari
2. Toque em Compartilhar
3. Selecione "Adicionar à Tela Inicial"
